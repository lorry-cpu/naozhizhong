# 自己的节奏

只供一人使用的本机浏览器应用。包含首页总览、今日计划、饮食计划、游戏娱乐、羽毛球、金币与风格、数据与设置。无需登录；日常使用无需联网或云数据库。

## 启动

1. 电脑需要安装 Node.js，使用同一个浏览器配置（建议 Chrome）访问本应用。
2. 首次获取源代码后，在本目录运行 `npm.cmd install` 和 `npm.cmd run build`；这是准备本机运行文件，首次安装开发依赖可能需要网络。
3. 双击 [`launcher/启动应用.cmd`](launcher/启动应用.cmd)。脚本会启动本机静态文件服务并打开浏览器。如果浏览器没有自动打开，请手动访问 **http://127.0.0.1:8765/**。
4. 运行期间保持启动窗口开启；关闭窗口或按 Ctrl+C 会停止本机服务。下次双击同一脚本即可继续使用。端口 8765 被占用时脚本会提示，请关闭占用端口的进程后重试。

服务仅绑定 `127.0.0.1`，不接收应用数据。构建产物在 `dist/`，应用运行时没有 CDN、账号或外网请求。更新源代码后再次运行 `npm.cmd run build` 才会更新浏览器中的页面。

## 日常使用

- **今日计划**：选择日期后创建一次性、每日或每周任务；选择难度、预计分钟和时间。可以开始、暂停、恢复计时，完成时用 0～100% 的滑块预览金币变动并确认打卡。打开浏览器时会补算过期任务，打开状态跨零点也会结算。重复规则可从指定的未来日期调整；已结算的历史保留。
- **金币**：简单／中等／困难每 30 分钟分别为 6／10／14 金币，零头向上算一档；不足 50% 会扣金币，余额允许为负数。见 [`RULES.md`](RULES.md) 的完整公式。金币页面展示流水并兑换风格；金币不足时不能兑换。
- **饮食**：记录当天吃什么、几点吃及实际花费。花费留空表示尚未记录，填写 0 表示实际花费零元。
- **游戏娱乐**：分别填写计划开始时间、计划分钟和实际分钟；可查看当天及本周汇总。
- **羽毛球**：记录每次打球的起止时间、消耗球数、训练内容和感受。
- **首页与设置**：首页的摘要来自真实记录，快速备忘点击“保存备忘”后写入本机；设置页展示累计统计及备份入口。

## 数据与恢复

所有数据存储在当前浏览器对固定地址 `http://127.0.0.1:8765/` 的 IndexedDB 内。正常刷新、关闭浏览器和重启电脑后仍会保留。更换浏览器配置、改变访问地址、开启隐私窗口或清除该站点数据可能导致看不到原有数据。

请在“数据与设置”定期点击“导出完整备份”，把 JSON 文件保存在自己选择的位置。恢复时选中备份文件，检查页面列出的替换范围，再点击“确认替换并恢复”。恢复会**整体替换**当前记录，建议先导出现有数据；无效文件不会替换原数据。最后一次导出时间会显示在设置页。

如果打不开应用，先检查启动窗口中的 Node.js、构建文件或端口错误；如果页面打开但无法保存，查看“本机数据”的状态，确认不是隐私模式，随后及时导出能够读取的数据。浏览器之间的数据不会自动同步。

## 开发验证

在项目目录执行 `npm.cmd run build` 和 `npm.cmd test`。测试包括规则单元测试、实际 Chrome 浏览器中的跨零点、计时重开、离线导航、事务回滚、双标签兑换、三类生活记录以及完整备份恢复。测试使用临时浏览器配置，不会读取日常浏览器里的个人记录。
