# 闹之钟

只供一人使用的本机浏览器应用。包含首页总览、备忘录、今日计划、饮食计划、游戏娱乐、羽毛球、金币与风格、数据与设置八个页面。无需登录；日常使用无需联网或云数据库。

采用 [MIT 许可证](LICENSE)。界面所用第三方中文字体**不包含在本仓库中**，其版权归各字体厂商所有，MIT 不适用于这些字体文件。

## 启动

1. 电脑需要安装 Node.js，使用同一个浏览器配置（建议 Chrome）访问本应用。
2. 首次获取源代码后，在本目录运行 `npm.cmd install` 和 `npm.cmd run build`；这是准备本机运行文件，首次安装开发依赖可能需要网络。
3. 双击 [`launcher/启动应用.cmd`](launcher/启动应用.cmd)。脚本会启动本机静态文件服务并打开浏览器。如果浏览器没有自动打开，请手动访问 **http://127.0.0.1:8765/**。
4. 运行期间保持启动窗口开启；关闭窗口或按 Ctrl+C 会停止本机服务。下次双击同一脚本即可继续使用。如果闹之钟已经在运行，脚本会直接打开页面；端口 8765 被其他程序占用时脚本会提示，请关闭占用端口的进程后重试。

服务仅绑定 `127.0.0.1`，不接收应用数据。构建产物在 `dist/`，应用运行时没有 CDN、账号或外网请求（**字体下载除外**，见下文）。更新源代码后再次运行 `npm.cmd run build` 才会更新浏览器中的页面。

## 字体

15 款中文字体（含默认的思源宋体）**不打进安装包**：它们合计约 194MB，放进仓库会让 `git clone` 变得非常慢，因此改为**首次使用时按需下载**，并缓存到本机 IndexedDB。

- 打开「金币与风格」页，**点击某个字体卡片里的预览文字**即可下载该字体，进度会显示在卡片上。
- 下载过的字体会缓存，之后切换无需再联网；「数据与设置」页会显示缓存占用，并提供“清除字体缓存”。
- 字体缓存**不包含在备份文件里**（体积太大），恢复备份后如需使用请重新下载。
- **字体下载失败不影响使用**：设置仍会保存，页面会回退到系统自带的中文字体，功能完全正常。

### 维护者：发布字体文件

字体文件通过 GitHub Releases 分发。发布新版本时：

```bash
node scripts/pack-fonts.mjs --check   # 检查 public/fonts 下 15 个 .ttf 是否齐全
node scripts/pack-fonts.mjs           # 生成 release/fonts.tgz
```

1. 把 `.ttf` 放回 `public/fonts/`（该目录已被 `.gitignore` 忽略，不会进仓库）；
2. 在 GitHub 建一个 **tag 为 `fonts-v1`** 的 Release；
3. 把 15 个 `.ttf` **逐个作为 Release 附件上传**（不要只传压缩包，运行时按 `<base>/<id>.ttf` 取单个文件）；
4. 修改 [`src/domain/fonts.ts`](src/domain/fonts.ts) 里的 `FONT_BASE_URL` 为你自己的仓库地址。

> 构建时 Vite 默认会把 `public/` 整个复制进 `dist/`，所以 [`vite.config.ts`](vite.config.ts) 里加了一个插件，在构建结束后删除 `dist/fonts`，确保安装包和构建产物都不含字体。

## 日常使用

顶部导航栏从左到右是品牌「闹之钟」、七个模块图标按钮，以及右侧的壁纸和余额按钮；点击品牌回到首页总览，点击余额进入金币页面。

- **首页总览**：摘要来自真实记录，显示今日计划完成进度、当天饮食、娱乐、最近一次打球，并提供快速备忘；备忘点击“保存备忘”后写入本机。
- **备忘录**：按日期保存和查看每天的备忘内容。同一天的首页快速备忘与备忘录共用同一份内容。
- **今日计划**：选择日期后创建一次性、每日或每周任务；选择难度、预计分钟和时间。可以开始、暂停、恢复计时，完成时用 0～100% 的滑块预览金币变动并确认打卡。打开浏览器时会补算过期任务，打开状态跨零点也会结算。重复规则可从指定的未来日期调整；已结算的历史保留。
- **金币**：简单／中等／困难每 30 分钟分别为 6／10／14 金币，零头向上算一档；不足 50% 会扣金币，余额允许为负数。见 [`RULES.md`](RULES.md) 的完整公式。金币页面展示流水并兑换风格；金币不足时不能兑换。
- **饮食**：记录当天吃什么、几点吃及实际花费。花费留空表示尚未记录，填写 0 表示实际花费零元。
- **游戏娱乐**：分别填写计划开始时间、计划分钟和实际分钟；可查看当天及本周汇总。
- **羽毛球**：记录每次打球的起止时间、消耗球数、训练内容和感受。
- **数据与设置**：展示累计统计、当前风格、备份入口、字体缓存占用和本机存储状态。

今日计划、饮食、娱乐和羽毛球四个页面都用月历选择日期，日历格子里的小数字表示当天已有记录数。

## 壁纸

导航栏右侧的壁纸按钮打开“设置壁纸”弹窗：导入一张本机图片作为壁纸，用滑块调整不透明度（0～100%），或清除壁纸。壁纸会覆盖导航栏和全部模块页面，图片保存在本机，刷新和重启后仍在。

## 数据与恢复

所有数据存储在当前浏览器对固定地址 `http://127.0.0.1:8765/` 的 IndexedDB 内。正常刷新、关闭浏览器和重启电脑后仍会保留。更换浏览器配置、改变访问地址、开启隐私窗口或清除该站点数据可能导致看不到原有数据。

请在“数据与设置”定期点击“导出完整备份”，把 JSON 文件保存在自己选择的位置。恢复时选中备份文件，检查页面列出的替换范围，再点击“确认替换并恢复”。恢复会**整体替换**当前记录，建议先导出现有数据；无效文件不会替换原数据。最后一次导出时间会显示在设置页。

如果打不开应用，先检查启动窗口中的 Node.js、构建文件或端口错误；如果页面打开但无法保存，查看“本机数据”的状态，确认不是隐私模式，随后及时导出能够读取的数据。浏览器之间的数据不会自动同步。

## 开发验证

在项目目录执行 `npm.cmd run build` 和 `npm.cmd test`。测试包括规则单元测试、实际 Chrome 浏览器中的跨零点、计时重开、离线导航、事务回滚、双标签兑换、三类生活记录、按日期备忘、月历选日、品牌与壁纸，以及完整备份恢复。测试使用临时浏览器配置，不会读取日常浏览器里的个人记录。

另外两个文件不含正式运行代码：[`navigation-preview.html`](navigation-preview.html) 是顶部导航的静态预览页，[`DEVELOPMENT_LOG.md`](DEVELOPMENT_LOG.md) 记录各阶段的实现与验证。
